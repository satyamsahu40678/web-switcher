Web Switcher extension privacy policy

Updated 27 October 2026. This policy describes the default local-mapping extension distributed from satyamsahu40678/web-switcher. It does not describe an independently operated registry service, the separate web application, or a modified extension.

What the extension processes

You choose source and destination origins. The extension processes eligible navigation URLs locally to apply your mappings, validate current policy, remove query/fragment data, and request confirmation for sensitive or ambiguous links. Invoking the popup lets it inspect the current tab's origin. It does not require access to browser history or cookies.

Local storage and retention

Mappings, preferences and validation state are stored in your browser profile. Recent activity records source/destination origins and timestamps, not original page paths, queries or fragments. Activity uses a 24-hour retention window; expired entries are removed during extension maintenance. If the browser is closed, cleanup resumes when it runs again. Mapping expiry stops routing; it does not necessarily delete the saved mapping.

You can clear activity, remove mappings, delete local mappings/activity or export settings from the options page. Exported files contain your mapping origins and should be protected by you. Removing the extension normally removes its local extension storage. Chrome or your device's backups are governed by their own settings.

Network transmission and third parties

The default build has no configured remote registry endpoint, publisher analytics, advertising, or browsing-history upload. No account is needed for manual mappings. When you choose to navigate to a destination, that website receives an ordinary browser request under your browser's normal privacy/session behavior. Cookies and logged-in sessions are not migrated across domains by Web Switcher.

A separately configured registry build can download signed data from its fixed HTTPS endpoint; that server sees connection metadata such as IP address and request time. Before distributing such a build, its operator must publish matching endpoint, server retention and contact disclosures. This local-only policy alone is not a complete server-service policy.

Permissions and control

Storage saves your local choices; declarative network request rules handle eligible selected-site navigation; active-tab access supports the user-invoked popup; alarms perform maintenance. Optional website permissions are requested for the specific source you select. You can deny or revoke access, pause switching, and uninstall through Chrome's extension settings.

Use of data

The default extension publisher does not receive local mappings or activity and does not sell them, use them for advertising, or upload them for unrelated purposes. A manual mapping expresses your choice, not verified ownership or a guarantee that destination content is safe.

Contact and changes

Use the developer contact shown on the Chrome Web Store listing for private questions. Before a listing exists, use the repository owner's published contact route on GitHub. General issues can be reported in the repository issue tracker; do not post private browsing URLs, passwords or personal evidence publicly. Material changes to the distributed extension's data practices must be reflected in this policy and its Store disclosures.
