Web Switcher extension privacy policy

Updated 28 October 2026. This policy describes the default browser-side continuity extension distributed from satyamsahu40678/web-switcher. It covers automatic continuity checks, followed-site memory and optional manual overrides. It does not describe an independently operated registry service, the separate web application, or a modified extension.

What the extension processes

You enter an old website address or invoke the popup on the current tab. The extension can investigate explicit HTTP/page-declared move signals without asking you to enter a new destination. Initial page paths, queries and fragments are discarded before the root probe. Selected response headers and bounded page content are parsed in memory without executing remote scripts. Supported move signals and valid remembered origin links form an observed successor chain; familiar names, logos and ordinary links are not identity proof.

If you explicitly choose to follow a source, eligible later top-level GET visits pass through a packaged local gate that checks its current chain. Cross-domain following opens a discovered homepage without transferring the original query or fragment; sensitive/ambiguous links can require confirmation. If a source is reachable and has no established move, the gate can resume the original same-origin URL without switching domains. Manual overrides remain a separate user choice. Invoking the popup permits inspection of the current tab's origin. Web Switcher does not require the browser history or cookies permissions.

Local storage and retention

Followed source origins, enabled/paused settings, manual mappings, preferences and validation state are stored in your browser profile. Remembered successor edges contain source/destination origins, evidence type and observation/expiry timestamps, not original page paths, queries or response bodies. The current limits are 50 followed sources and 250 edges. An edge is valid for at most seven days after its latest observation; expired edges are pruned on graph reads and periodic maintenance and cannot authorize a remembered fallback. A followed-source subscription persists until you pause, forget or clear it.

Recent routing activity records origin pairs and timestamps rather than original page URLs. Activity uses a 24-hour retention window and is pruned during extension maintenance. If the browser is closed, cleanup resumes when it runs again. Manual mapping expiry stops its routing but does not necessarily delete the saved mapping. Browser/device backups are governed by their own settings.

You can clear recent activity, pause following, forget a selected website and its associated continuity memory, or use Delete all local data in options to remove mappings, followed sites, graph history, activity and the catalog cache. Public catalog rollback and alias-reservation security metadata is retained: deleting settings, expiry or withdrawal must not turn a formerly signed source into an unverified route. This retained metadata contains public registry sequence/digest information and source origins, not private browsing paths or response bodies. The current export/import feature backs up manual mappings, not followed-source enrollment or the learned graph. Protect exported mapping files. Removing the extension normally removes its local extension storage; switching between unpacked and Store installations can create different extension IDs/storage.

Direct website requests and third parties

This extension is not network-free. Pressing Find current address or checking a followed source can send bounded requests directly from your browser to that source and its explicitly declared successors. Each contacted website can see ordinary connection/request metadata, including your IP address and request timing. Those operators' own policies govern their server logs; the extension publisher does not control those logs. Per-origin access is requested before checking an origin unless you explicitly grant optional access across HTTPS websites.

Probe requests omit cookies/HTTP credentials, use no referrer, remove query/fragment data and do not execute downloaded JavaScript. Redirects are requested in manual mode so a next target can be inspected before a separate permitted request. Public-path redirect targets may be visited transiently while resolving the chain; only origin links are retained. Browser-side hostname/literal checks do not independently pin DNS answers or connected IPs, so they are not a guarantee of isolated public-only egress.

The default build has no configured remote registry endpoint, publisher analytics, advertising or general browsing-history upload. No account or backend is required for browser-side continuity. When you choose to open a resulting website, or enable following and navigate to a selected source, ordinary browser navigation is subject to your browser's normal site/session behavior. Web Switcher does not migrate cookies or logged-in sessions across domains.

A separately configured registry build can also download signed data from its fixed HTTPS endpoint; that server sees connection metadata. Before distributing such a build, its operator must publish matching endpoint, server-retention and contact disclosures. This browser-extension policy is not a complete policy for a separately operated server service.

Permissions and control

Storage saves local settings and bounded continuity memory. Declarative network request rules intercept eligible navigation only for selected/granted followed sources or mappings. Active-tab access supports the user-invoked popup. Alarms perform maintenance. The webRequest permission reads response headers/error events only for correlated active probes initiated by this extension; unrelated request events are ignored, not recorded as browsing history.

By default, selected-source and next-origin permissions are requested at a user gesture. An unchecked-by-default option lets you explicitly grant access across HTTPS websites so your chosen continuity chains can continue without a permission prompt at each new origin. That grant does not enroll every website, enable general browsing-history collection or change source-declared observations into verified ownership. You can deny/revoke access, pause individual/global switching, forget sites and uninstall in Chrome settings.

Use of data and trust limits

The default publisher does not receive your locally stored mappings, followed-site list or continuity graph and does not sell them, use them for advertising, or upload them for unrelated purposes. Direct probes necessarily reveal the contacted host to that website's operator as described above. Source-declared moves are observations, not independent registry review, owner verification or a guarantee that destination content is safe. A dead source with no usable declaration or remembered successor can remain unknown.

Contact and changes

Use the developer contact shown on the Chrome Web Store listing for private questions. Before a listing exists, use the repository owner's published contact route on GitHub. General issues can be reported in the repository issue tracker; do not post private browsing URLs, passwords or personal evidence publicly. Material changes to the distributed extension's data practices must be reflected in this policy and its Store disclosures.
